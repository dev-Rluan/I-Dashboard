# I-Dashboard 기획서

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | I-Dashboard (Infrastructure Dashboard) |
| 목적 | 서버 인프라 상태를 실시간으로 시각화하여 운영 효율 향상 |
| 실행 방식 | 서버에서 직접 구동 — CLI(TUI) 또는 웹 브라우저 접근 |
| 대상 사용자 | 서버 운영자, DevOps 엔지니어 |

---

## 2. 제품 구성

```
I-Dashboard/
├── core/              # 공통 데이터 수집 모듈
│   ├── ports.py
│   ├── firewall.py
│   ├── resources.py
│   ├── network.py
│   ├── processes.py
│   ├── services.py
│   └── docker.py
│
├── cli/               # TUI 버전 (rich 기반)
│   └── main.py
│
└── gui/               # 웹 대시보드 버전
    ├── backend/       # FastAPI
    └── frontend/      # React + Vite
```

### 2-1. CLI 버전
- 터미널에서 `python cli/main.py` 로 즉시 실행
- SSH 접속만으로 확인 가능, 의존성 최소화
- `rich` 라이브러리 기반 TUI, 키보드 네비게이션

### 2-2. GUI 버전
- 웹 브라우저로 접근 (`http://서버IP:포트`)
- FastAPI 백엔드가 `core/` 모듈 호출 → REST API / WebSocket 노출
- React + Vite 프론트엔드, 실시간 차트 및 테이블

## 3. 기능 명세

### 3-1. 포트 스캐너 (Port Scanner) ★ 핵심
- 열린 포트 / 닫힌 포트 시각적 표시 (초록 / 빨강)
- 포트별 서비스명 자동 매핑 (22=SSH, 80=HTTP, 443=HTTPS 등)
- Well-known / Registered / Dynamic 포트 범위 구분
- 포트 클릭(GUI) / 선택(CLI) 시 상세 정보 표시 (PID, 프로세스명, 사용자)
- 커스텀 포트 범위 스캔

### 3-2. 방화벽 상태 (Firewall Status) ★ 핵심
- `iptables` / `ufw` / `firewalld` 자동 감지
- 인바운드 / 아웃바운드 규칙 테이블 표시
- 허용(ACCEPT) / 차단(DROP/REJECT) 색상 구분
- 방화벽 활성화 / 비활성화 상태 배지

### 3-3. 시스템 리소스 (System Resources)
- CPU: 코어별 사용률 실시간 게이지
- 메모리: 사용량 / 가용량 / 캐시 구분
- 디스크: 마운트 포인트별 용량 및 I/O 속도
- 스왑 사용률

### 3-4. 네트워크 인터페이스 (Network Interfaces)
- 인터페이스별 IP, MAC, 상태 (UP / DOWN)
- 실시간 인바운드 / 아웃바운드 트래픽 그래프
- 패킷 손실률, 에러 카운트

### 3-5. 프로세스 모니터 (Process Monitor)
- CPU / 메모리 상위 프로세스 순위 표
- 프로세스 상태 (running / sleeping / zombie)
- 검색 및 필터 기능

### 3-6. 시스템 서비스 (Systemd Services)
- systemd 서비스 목록 및 상태 (active / failed / inactive)
- 실패한 서비스 알림 강조
- 서비스별 최근 로그 팝업 (GUI) / 표시 (CLI)

### 3-7. 로그 뷰어 (Log Viewer)
- `/var/log/syslog`, `/var/log/auth.log`, nginx/apache 로그 등
- 키워드 검색, ERROR / WARN 필터링
- SSH 로그인 시도 이력 (brute-force 패턴 감지)

### 3-8. 도커 컨테이너 (Docker Monitor) *(선택)*
- 실행 중인 컨테이너 목록 및 상태
- 컨테이너별 CPU / 메모리 사용량
- 컨테이너 로그 확인

```
┌─────────────────────────────────────────────────────────────┐
│  I-Dashboard              [hostname]  [2026-04-23 12:00:00] │
├──────────┬──────────────────────────────────────────────────┤
│          │                                                   │
│ SIDEBAR  │  ┌──────────┐ ┌──────────┐ ┌──────────┐         │
│          │  │ CPU 45%  │ │ MEM 62%  │ │ DISK 78% │         │
│ ▶ 개요   │  └──────────┘ └──────────┘ └──────────┘         │
│ ▶ 포트   │                                                   │
│ ▶ 방화벽 │  ┌─────────────────────────────────────────────┐ │
│ ▶ 리소스 │  │  포트 현황                                  │ │
│ ▶ 네트워크│  │  ● 22 SSH  ● 80 HTTP  ○ 8080  ● 443 HTTPS │ │
│ ▶ 프로세스│  └─────────────────────────────────────────────┘ │
│ ▶ 서비스 │                                                   │
│ ▶ 로그   │  ┌─────────────────────────────────────────────┐ │
│ ▶ 도커   │  │  방화벽 규칙 / 서비스 상태                  │ │
```

- 다크 모드 기본 (서버 운영 환경 특성상)
- WebSocket 실시간 자동 갱신 (기본 5초 간격, 조절 가능)
- 반응형 레이아웃 (태블릿 / 모바일 접근 가능)
- 위험 상태 시 빨간색 강조 + 브라우저 알림 (선택)

## 5. 기술 스택

| 영역 | 기술 | 이유 |
|------|------|------|
| 공통 수집 | Python + `psutil` | 크로스 플랫폼 시스템 정보 수집 |
| 포트 / 방화벽 | `socket`, `subprocess` (`ss`, `ufw`, `iptables`) | 로컬 직접 조회 |
| CLI TUI | `rich` | 컬러, 테이블, 패널 지원 |
| Backend | FastAPI | 빠른 개발, WebSocket 내장 |
| Frontend | React + Vite | SPA, 컴포넌트 재사용성 |
| 차트 | Recharts | React 친화적 |
| 스타일 | Tailwind CSS | 다크모드 UI 빠른 구성 |

## 6. 보안 고려사항

- 대시보드에 Basic Auth 또는 JWT 로그인 적용 (외부 노출 방지)
- 읽기 전용 운영 — 서버 제어 기능 없음, 모니터링만
- HTTPS 설정 권장 (self-signed cert 지원)
- 민감 정보 (비밀번호, 개인키) 표시 제외
- 방화벽 수집은 `sudo` 권한 필요 시 명시적 안내
